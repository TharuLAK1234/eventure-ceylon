🖥️ STEP 2: ON OTHER MACHINE
When someone uses the pen drive on another computer:

What they need:
✅ PHP 8.2+ installed
✅ XAMPP installed (or standalone PHP)
Steps to run:
Step 1: Copy folder from pen drive to their computer

C:\Users\[TheirName]\Desktop\eventure-ceylon\
Step 2: Open Command Prompt and run:

cd C:\Users\[TheirName]\Desktop\eventure-ceylon\public
C:\xampp\php\php.exe -S localhost:8000
Step 3: Open browser:

http://localhost:8000
✅ Done!

⚠️ IMPORTANT NOTES
Issue	Solution
PHP not found	Install XAMPP first
Port 8000 taken	Use different port: php.exe -S localhost:8001
Can't access	Make sure server is running
Files corrupted	Copy carefully, don't interrupt transfer
📱 NETWORK ACCESS
Can they access from another computer on the network?

Yes! Instead of localhost:8000, use:

http://[YOUR_IP_ADDRESS]:8000
Find your IP:

ipconfig
Look for: IPv4 Address: 192.168.x.x

Then they can access from their computer:

http://192.168.1.100:8000
